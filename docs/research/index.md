# Исследования

Здесь будут появляться отдельные исследования. Для новой работы создайте Markdown-файл в этой папке, добавьте его в раздел `Исследования` в `mkdocs.yml`, затем выполните строгую сборку.

Шаблон структуры:

```text
# Название исследования
## Вопрос
## Методика
## Данные и код
## Результаты
## Вывод
```
