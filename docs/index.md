# Исследовательские материалы

Этот сайт хранит результаты исследований и практических заданий. Исходный формат публикаций — Markdown, а MkDocs собирает из них статический HTML.

## Навигация

- [Подходы к публикации](publication-methods.md) — сравнение двух вариантов GitHub Pages.
- [T1](t1.md) — сравнительный анализ генераторов статических сайтов.
- [P2](p2.md) — страница для стресс-теста научного контента.

## Стек

- Python 3.13+
- MkDocs 1.6.1
- Material for MkDocs 9.6.14
- GitHub Actions и GitHub Pages
- Артефакт статического сайта для Helios Static HTML
