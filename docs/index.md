# Исследовательские материалы

Этот сайт хранит отчёты по практическим заданиям, результаты экспериментов и сопровождающие материалы. Исходный формат публикаций — Markdown, а MkDocs собирает из них статический HTML.

## Навигация

- [Отчёт по заданию 1](assignment-1.md) — выбор генератора, настройка CI/CD и план публикации.
- [Исследования](research/index.md) — каталог отдельных исследовательских работ.
- [Эксплуатация](operations.md) — локальная разработка, сборка и развёртывание.

## Стек

- Python 3.13+
- MkDocs 1.6.1
- Material for MkDocs 9.6.14
- GitHub Actions и GitHub Pages
- Артефакт статического сайта для Helios Static HTML
